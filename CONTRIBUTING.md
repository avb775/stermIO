# 🤝 Contributing to stermIO Protocol

Thank you for considering contributing to **stermIO**! 🚀  
We are building a future-proof real-time protocol, and your ideas, improvements, and feedback are highly valuable.

---

## 🛠 How to Contribute

**1. Read the Spec**

Start by reviewing the core [Protocol Spec](spec/protocol-spec.md).  
Understanding the design principles will help you suggest meaningful changes.

---

**2. Create an Issue**

If you want to:
- Suggest a new feature
- Report a problem or typo in the spec
- Propose an improvement or extension

👉 Please [open an issue](https://github.com/yourname/stermIO-protocol/issues/new).

Use the appropriate issue template if available.

---

**3. Fork the Repo**

- Click **Fork** on GitHub.
- Clone your fork locally:

```bash
git clone https://github.com/yourusername/stermIO-protocol.git
```

---

**4. Create a New Branch**

Follow this pattern:

```bash
git checkout -b feature/my-feature-name
```

Examples:
- `feature/session-resume-improvements`
- `docs/fix-typo-in-message-types`
- `spec/add-stream-priority`

---

**5. Make Your Changes**

- Update the relevant `.md` files in `/spec` or `/docs`.
- If you propose a major change, explain your reasoning clearly.
- Keep your writing clear, consistent, and concise.

---

**6. Commit Your Changes**

Use clear commit messages:

```bash
git commit -m "Spec: Improve session resume flow description"
```

---

**7. Push and Create a Pull Request**

```bash
git push origin feature/my-feature-name
```

Then go to GitHub and create a Pull Request (**PR**).

Describe **what** you changed and **why** in the PR description.

---

## 📜 Style Guide for Spec

- Use simple, consistent language.
- Keep examples in code blocks (` ```json `).
- Break down sections logically.
- Prefer short sentences for better readability.

---

## 💬 Code of Conduct

We expect all contributors to follow respectful, welcoming communication.  
Please treat each other kindly and help us maintain a friendly community.

---

## 🔥 Bonus Points

- Link to relevant sections when suggesting edits.
- Help review and comment on open pull requests.
- Share your ideas for real-world use cases.

---

# 🛰️ Let's build the best real-time protocol, together!

Thank you for contributing to **stermIO**! 🙏
